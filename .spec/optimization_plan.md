# 全书内容密度与合规性优化计划

## 优化目标
基于 `.cursor/rules/constitution.md`，全面消除书中的啰嗦表述、重复比喻、多余预防针，并严格校准所有技术术语和格式规范，使全书达到“工业级技术文档”的精炼度。

## 执行策略
由于全书字数较多，将分为 3 个批次，通过启动 3 个独立的 AI Subagent 并行处理，以最大化上下文理解和处理速度。

> 
> **绝对不可违背的红线**：
> 请你静默读取并严格执行 `@.cursor/rules/constitution.md` 中的全部规范。

## 分批并行任务设计

### 批次 1：前言与基础技能篇（文件：00, 01, 02）
- **特定指令（注入 Agent A）**：
  - **针对 `00-前言.md`**：重灾区！请大刀阔斧地删减：把“工具无关”的 3 次重复删减为 1 次；直接删除“这本书不是什么”这种否定式段落；将“适用边界”的大段引用压缩为一句话嵌入正文；合并“前置条件”与“工具准备”。
  - **针对 `01-清晰表达-CRC三要素.md`**：严重违反“一个观点只说一次”！目前每个 CRC 要素有 3 个 ❌/✅ 的正反对比，太啰嗦。**硬性要求**：每个要素只保留 **1 个生活比喻对比 + 1 个信息表 + 编程对照只给✅的正确示范（删除❌的反面猜测）**。全章的反面教材集中在 1.3 节统一展示即可。
