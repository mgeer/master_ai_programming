# Review 报告：Ch3 + Ch4 + Ch5

## 文件：03-Agent.md

### 角色 B 发现
- 🟡 3.2 提到"工具赋予 AI 真正的行动能力"，但"工具"在这里是技术术语（Agent 的工具调用），首次出现未解释。新用户可能理解为泛指工具，与实际含义有偏差。建议在括号内补一句：（读写文件、执行命令等）。
- 🟡 3.4 提到"给 Agent 授权前想清楚"，但全章没有说明如何启动 Agent 模式、如何在 Claude Code 中实际操作。学员读完知道"Agent 是什么"，但不知道"怎么打开它"。建议在 3.3 案例前补一句操作说明。

- 🟡 4.4 要点中："只保留 CRC 核心"——同上，应改为"只保留 3C 核心"（此条已在 plan.md 中标注修改，但正文未同步）。

## 文件：05-AI-Rules开发规范.md

### 角色 B 发现
- 🟢 5.3 案例给了生成 CLAUDE.md 的提示词，但没有展示 AI 会生成什么样的内容。对第一次接触的学员来说，看到一份示例输出会更有代入感。可在提示词后加一个折叠/截图式的简短示例。

### 角色 C 发现
- 🟡 5.5 练习依赖 Ch4 的前序产出物（"将上一章写好的 3 条 token 节省规则一并加入"）。若讲师单独抽取 Ch5 作为培训模块，学员需要先完成 Ch4 练习。建议在练习中加一句备注："若未完成 Ch4 练习，可先自行制定 2-3 条行为约束作为替代"。
