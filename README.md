# AI 编程实战手册

> 写给已经在用 AI 编程工具（Claude Code、Cursor 等），但仍受困于"代码失控、反复返工、缺少系统方法论"的开发者。

本书以 **SDD（Specification-Driven Development，规范驱动开发）** 为核心框架，覆盖从向 AI 清晰表达需求，到用 Agent 自主执行，到用规范和工具系统化开发的完整工作流。

## 阅读建议

- **系统学习**：按章节顺序阅读，结合书中案例边看边练
- **快速上手**：从第 3 章（Agent）开始，直接套用书中的提示词模板
- **培训使用**：每章独立成模块，可单独抽取使用
