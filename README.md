# AI 编程实战手册

> 写给想用 AI 提升编程效率，但还不知道怎么用才有效的程序员。

本书覆盖 AI 编程所需九项核心能力：从向 AI 清晰表达（3C 要素、多轮对话），到 AI 工具使用（Agent、Token 管理、AI Rules），到规范驱动开发（SDD 方法论、SKILL、MCP、SDD 工具实战）。每章教一项独立技能，学完即可用。
