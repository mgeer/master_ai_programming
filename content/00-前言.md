# 前言

## 这本书是写给谁的

写给**想用 AI 提升编程效率，但还不知道怎么用才有效**的程序员。

你可能已经试过让 ChatGPT、Claude 或 Copilot 帮你写代码，但体验不太好——输出的代码不符合预期、反复修改效率反而更低、不知道什么时候该用、什么时候不该用。这本书帮你解决这些问题。

## 这本书是什么

《AI 编程实战手册》：覆盖 AI 编程所需九项核心能力，从向 AI 清晰表达，到让 Agent 自主完成任务，到用规范和工具系统化开发。

每章教一项独立技能，配一个上手练习，学完即可用。

## 前置条件与工具准备

第一、二章介绍与 AI 沟通的通用方法，核心概念无需编程基础，但示例以编程场景为主。从第三章开始，你需要：
- **编程能力**：熟悉一门编程语言，能独立完成基础开发。
- **AI 工具**：安装 [Claude Code](https://docs.anthropic.com/claude-code)（本书主线工具）。推荐配置：VS Code + Claude Code 扩展——代码编辑器与 AI 面板并排，`@` 文件引用直接可用，无需切换窗口。其他编辑器（Cursor、Windsurf 等）也支持本书大部分内容，但 Ch7（SKILL）和 Ch8（MCP）的命令示例以 Claude Code 为准。
- **Markdown 语法**：用于编写规范和文档。

## 怎么读这本书

**如果你时间充裕**：从第一章顺序读到最后，每章配套练习边读边做。

**如果你想快速上手**：先读 Ch1-Ch3 掌握基本功，之后按需查阅后续章节。

**如果你只需要某项能力**：各章独立，直接跳到对应章节。

**全书章节：**

```text
第一章  3C 要素
第二章  多轮对话技巧
第三章  Agent（让 AI 真正干活）
第四章  Token 管理
第五章  开发规范（AI Rules）
第六章  SDD 方法论
第七章  SKILL（可复用提示词）
第八章  MCP（模型上下文协议）
第九章  SDD 工具实战
附录    延伸学习资源
```

## 如何用于培训

本书同时适合作为团队 AI 编程培训教材：
- 每章对应一个独立培训模块，可单独抽取使用
- 章末练习即课堂任务，讲师无需另行备课
- 各章独立，可按需组合成多次培训

## 最后

AI 工具快速迭代，但和 AI 清晰沟通、用规范约束 AI 行为、让 Agent 自主完成任务——这些能力不会过时。
