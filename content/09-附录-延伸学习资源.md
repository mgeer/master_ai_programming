# 附录：延伸学习资源

## 方法论回顾

本书介绍的方法论体系：

```
CRC 三要素（清晰表达）
  └── Context / Requirement / Constraint

多轮对话技巧
  └── 苏格拉底式提问 / 角色扮演 / 挑错优化 / 元提示 / 对话管理

CODE 方法论（项目开发）
  ├── C - Clarify（澄清需求）
  ├── O - Outline（架构设计 - BASER）
  │     └── Business / Architecture / Security / Environment / Rules
  ├── D - Develop（开发实现 - STIR）
  │     └── Split / Test / Implement / Review
  └── E - Evaluate（整体评估）
        └── 功能验证 / 整体质量 / 性能评估 / 安全审查
```

## 延伸阅读

### Prompt Engineering（提示词工程）

本书讲的 CRC、角色扮演等技巧，属于 Prompt Engineering 的范畴。想深入了解：

- [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering) — OpenAI 官方指南
- [Anthropic Prompt Engineering](https://docs.anthropic.com/claude/docs/prompt-engineering) — Claude 的提示词最佳实践
- [Prompting Guide](https://www.promptingguide.ai/) — 社区维护的全面教程

### 领域驱动设计（DDD）

第五章业务架构的方法论基础。适合处理复杂业务系统：

- Eric Evans《领域驱动设计：软件核心复杂性应对之道》（中文版：人民邮电出版社）— DDD 的开山之作
- Vaughn Vernon《实现领域驱动设计》（中文版：电子工业出版社）— 更注重实操

### 测试驱动开发（TDD）

第六章 STIR 的 T（测试先行）源自 TDD：

- Kent Beck《测试驱动开发》（中文版：人民邮电出版社）— TDD 的经典之作
- [pytest 官方文档](https://docs.pytest.org/) — Python 测试框架

### 项目技术栈

本书案例使用的技术栈文档：

- [FastAPI 官方文档](https://fastapi.tiangolo.com/) — Web 框架（含中文版）
- [SQLAlchemy 2.0 文档](https://docs.sqlalchemy.org/) — ORM 框架
- [Pydantic V2 文档](https://docs.pydantic.dev/) — 数据校验
- [httpx 文档](https://www.python-httpx.org/) — HTTP 客户端（用于测试）

### 软件架构

第五章 BASER 涉及的架构设计知识：

- Robert C. Martin《架构整洁之道》（中文版：电子工业出版社）— Clean Architecture
- Martin Fowler《企业应用架构模式》（中文版：机械工业出版社）— 经典架构模式
- [The Twelve-Factor App](https://12factor.net/zh_cn/) — 现代应用开发方法论

### Clean Code

第五章开发规范中提到的代码质量标准：

- Robert C. Martin《代码整洁之道》（中文版：人民邮电出版社）— Clean Code 的经典之作
- Martin Fowler《重构：改善既有代码的设计》（中文版：人民邮电出版社）— 重构方法论

### Web 安全

第五章 BASER 的 S（安全设计）和第七章安全审查涉及的安全知识：

- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — Web 应用最常见的十大安全风险
- [OWASP API Security Top 10](https://owasp.org/www-project-api-security/) — API 安全的十大风险，与本书案例直接相关

### AI 编程工具

- [Cursor](https://cursor.com/) — AI 代码编辑器
