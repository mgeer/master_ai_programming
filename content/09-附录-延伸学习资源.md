# 附录：延伸学习资源

## 方法论回顾

本书介绍的方法论体系：

```
CRC 三要素（清晰表达）
  └── Context / Requirement / Constraint

多轮对话技巧
  └── 苏格拉底式提问 / 少样本引导 / 角色扮演 / 方案对比 / 挑错优化 / 元提示 / 对话管理

CODE 方法论（项目开发）
  ├── C - Clarify（澄清需求）
  ├── O - Outline（架构设计 - BASER）
  │     └── Business / Architecture / Security / Environment / Rules
  ├── D - Develop（开发实现 - STIR）
  │     └── Split / Test / Implement / Review
  └── E - Evaluate（整体评估）
        └── 功能验证 / 整体质量 / 性能评估 / 安全审查
```

## 延伸阅读

AI 能帮你写代码，但不能替你做设计决策。你对软件工程的理解越深，给 AI 的指令就越精准，对 AI 产出的判断就越准确。

下面的资源都围绕一个目标：**提升你的设计思维和工程判断力**——这是 AI 时代最不会贬值的能力。

### Clean Code

代码质量判断力的起点，入门友好：

- Robert C. Martin《代码整洁之道》（中文版：人民邮电出版社）— 什么是好代码、什么是坏代码
- Martin Fowler《重构：改善既有代码的设计》（中文版：人民邮电出版社）— 如何系统地改善代码

### SOLID 原则与设计模式

良好的设计原则是让 AI 生成高质量代码的前提——当你在 Constraint 中要求"遵循单一职责原则"时，你需要知道这意味着什么：

- Robert C. Martin《敏捷软件开发：原则、模式与实践》（中文版：人民邮电出版社）— SOLID 原则的出处，同时涵盖常用设计模式
- Erich Gamma 等《设计模式：可复用面向对象软件的基础》（中文版：机械工业出版社）— GoF 设计模式经典

### 测试驱动开发（TDD）

第六章 STIR 的 T（行为测试先行）的理论基础：

- Kent Beck《测试驱动开发》（中文版：人民邮电出版社）— TDD 的经典之作

### 软件架构

第五章 BASER 涉及的架构设计知识，适合有一定经验后阅读：

- Robert C. Martin《架构整洁之道》（中文版：电子工业出版社）— Clean Architecture
- Martin Fowler《企业应用架构模式》（中文版：机械工业出版社）— 经典架构模式
- [The Twelve-Factor App](https://12factor.net/zh_cn/) — 现代应用开发方法论

### 领域驱动设计（DDD）

第五章业务架构的方法论基础。难度较高，适合处理复杂业务系统时深入学习：

- Eric Evans《领域驱动设计：软件核心复杂性应对之道》（中文版：人民邮电出版社）— DDD 的开山之作
- Vaughn Vernon《实现领域驱动设计》（中文版：电子工业出版社）— 更注重实操

### Web 安全

第五章 BASER 的 S（安全设计）和第七章安全审查涉及的安全知识：

- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — Web 应用最常见的十大安全风险
- [OWASP API Security Top 10](https://owasp.org/www-project-api-security/) — API 安全的十大风险，与本书案例直接相关

### AI 编程工具

本书的方法论不绑定特定工具，以下是目前主流的 AI 编程工具：

- [Cursor](https://cursor.com/) — AI 代码编辑器
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) — Anthropic 的终端 AI 编程工具
- [GitHub Copilot](https://github.com/features/copilot) — GitHub 的 AI 编程助手

### Prompt Engineering（提示词工程）

本书第二章已覆盖核心技巧。如果想更系统地了解提示词工程的全貌：

- [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering) — OpenAI 官方指南
- [Anthropic Prompt Engineering](https://docs.anthropic.com/claude/docs/prompt-engineering) — Claude 的提示词最佳实践
- [Prompting Guide](https://www.promptingguide.ai/) — 社区维护的全面教程

---

**最后一句话：**

工具和方法都会不断演进，但核心能力不会变：**清晰的思考、结构化的表达、严谨的工程实践。** 掌握了这些，无论 AI 工具怎么变化，你都能用好它。
