# 附录：延伸学习资源

本书覆盖了 AI 编程所需的九项核心能力——从向 AI 清晰表达，到 Agent 自主执行，到用规范和工具系统化开发。以下是值得关注的延伸资源。

---

## SDD 规范与标准

- **SDD 学术论文**
  [arXiv:2602.00180](https://arxiv.org/abs/2602.00180)
  详细阐述规范驱动开发的理论基础、流程设计和实验验证。适合想深入了解 Ch6/Ch9 方法论背后原理的读者。

---

## 工具与项目

- **GitHub Spec Kit**
  [https://github.com/github/spec-kit](https://github.com/github/spec-kit)
  GitHub 官方出品的 SDD 工具包，提供 `/specify`、`/plan`、`/tasks` 等命令，支持 Claude Code、Copilot 等主流 AI 工具。

- **Agent Skills 格式标准**
  [https://agentskills.io](https://agentskills.io)
  由 Anthropic 发起的 Skill 开放格式标准，已被 Claude Code、Cursor、VS Code 等工具采用，本书 Ch7 的 SKILL 机制基于此格式。

- **Anthropic Skills**
  [https://github.com/anthropics/skills](https://github.com/anthropics/skills)
  Anthropic 官方维护的 Skill 示例仓库，现成的斜杠命令可直接复用，也是学习如何写好 Skill 的参考样本（对应 Ch7）。

- **OpenSpec**
  [https://github.com/Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec)
  开源 SDD Skill 工具包，包含 `/opsx:propose`、`/opsx:apply`、`/opsx:archive` 等命令（对应 Ch9）。安装方式见仓库 README。
