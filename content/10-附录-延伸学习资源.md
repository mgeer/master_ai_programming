## 工具与项目

- **GitHub Spec Kit**

  [https://github.com/anthropics/skills](https://github.com/anthropics/skills)

## 推荐延伸学习路径

读完本书后，建议按以下方向深入：

1. **强化提示词能力**：读 Anthropic 官方提示词工程指南，对应 Ch1-2
2. **深入 Agent 机制**：读 Claude Code 官方文档，了解工具调用和权限控制，对应 Ch3
3. **提升 Token 效率**：实践 `@` 引用和对话分段策略，参考 Claude Code 官方文档，对应 Ch4
4. **完善规范文件**：参考各工具官方文档完善 CLAUDE.md 或对应规范文件，对应 Ch5
5. **扩展 SKILL 库**：浏览 Anthropic Skills 官方仓库，复用或改造现成命令，对应 Ch7
6. **探索 MCP 生态**：查找适合自己业务场景的 MCP（数据库、API、搜索），对应 Ch8
7. **深入 SDD 理论**：读 SDD 学术论文和 Spec Kit 文档，对应 Ch6-9
